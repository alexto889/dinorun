# Orange Dino Run

A simple endless-runner browser game: an orange dinosaur jumping over green cacti.
Built with plain HTML, CSS and JavaScript (no build step, no dependencies).

## Controls

- **Space / Up arrow / tap:** jump (also starts or restarts the game)
- **Down arrow:** fall faster

## Run locally

Open `index.html` in any modern browser.

## Deploy to Vercel

1. Sign in at [vercel.com](https://vercel.com) and choose **Add New > Project**.
2. Import the `alexto889/dinorun` GitHub repository.
3. Leave the settings as they are: Framework Preset **Other**, no build command, no output directory.
4. Click **Deploy**.

`vercel.json` adds clean URLs and basic security headers. Every push to the default branch redeploys automatically.
